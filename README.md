# Raj Vaibhav — Portfolio

Static single-page portfolio: hero illustration, case studies, and an animated crowd footer drawn on canvas.

- `index.html` — the whole site (HTML, CSS, JS inline)
- `footer/character.png` — transparent character illustration
- `footer/crowd.png` — transparent 5×3 crowd sprite sheet
- `resume.pdf` — resume linked from the site

## Deploy

No build step. On Vercel: import the repo, Framework Preset **Other**, leave build command empty, output directory `.` (root).

Locally: `npx serve .` and open http://localhost:3000
